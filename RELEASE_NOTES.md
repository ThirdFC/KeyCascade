# KeyCascade v1.0.0

A configurable keyboard waterfall overlay for rhythm games on Windows 10 and 11 (x64).

- Configure 1–32 keys, bindings, labels, colors, dimensions and placement.
- Transparent always-on-top overlay with mouse passthrough and an editable drag mode.
- Composition-driven animation with cached text and key graphics.
- Global Raw Input and keyboard-hook monitoring, press counts and hold-duration trails.
- JSON configuration import/export, tray controls and global shortcuts.
- English product name, executable metadata and window titles; Chinese settings UI.

Download and extract **KeyCascade-Windows-x64.zip**, then run **KeyCascade.exe**. Keep **KeyCascade.exe.config** beside the executable.

Use windowed or borderless fullscreen games. Coverage over exclusive fullscreen is not guaranteed. Requires .NET Framework 4.8. The executable is unsigned.
