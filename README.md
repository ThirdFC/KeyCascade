# KeyCascade

适用于 Windows 10 / 11（64 位）的音游按键可视化悬浮窗。无需安装包或 Node/Python 环境，使用 Windows 的 .NET Framework 4.8。

软件名称、可执行文件属性、窗口标题和托盘名称均为 **KeyCascade**；设置界面提供中文操作说明。

动画使用 WPF 的屏幕渲染时钟，随系统合成刷新节奏更新，不再使用 16ms 定时器限制绘制。按键与文字缓存为静态图形，按下状态或计数变化时才更新；没有尾迹或隐藏时停止动画循环。设置页会显示当前绘制帧率（程序提交频率，并非显示器实测呈现帧率）。最终流畅度仍受系统合成、显示刷新率和游戏负载影响。

## 启动

双击 `release/KeyCascade.exe`。首次运行显示设置与透明悬浮窗，默认 7 键：**S D F SPACE J K L**。按键长按时，条带从底部向上增长；松开后继续向上移动并渐隐。默认显示本次运行的按下次数，自动连发不会重复计数。

## 自定义

- 选择 4 / 7 / 8 键预设，或添加、删除按键（1–32 个）。预设只替换按键列表，保留当前窗口与瀑布流参数。
- 选中一行点击「录入绑定」，然后按下需要的物理键；支持方向键、空格、功能键、左右 Shift/Ctrl/Alt。不能重复绑定同一物理键。
- 表格中可编辑显示标签、颜色（`#RRGGBB`）、每个键的宽度、高度和 X/Y 偏移；「选择颜色」可打开系统调色板。
- 调整窗口 X/Y、瀑布流高度、速度、间距、整体不透明度和背景不透明度。尺寸采用 Windows 逻辑像素（DIP）。
- 点击「放到当前屏幕底部」居中定位，或「启用拖动模式」后直接拖动悬浮窗。拖动位置自动保存。按 **Ctrl+Alt+F9** 恢复鼠标穿透。
- 点击「应用并保存」让编辑生效。「试播 4 秒」会先应用并保存，再播放模拟条带，模拟条带不增加真实按键计数。
- 支持 JSON 配置导入与导出。配置保存到 `%APPDATA%\KeyCascade\settings.json`，更新时保留 `.bak` 备份。配置文件读取出错时会提示并暂用默认配置；再次保存会备份原文件。

## 游戏时使用

悬浮窗使用 Windows 原生 **TOPMOST** 窗口和周期性置顶刷新。默认**鼠标穿透**，窗口不抢占键盘焦点，监听回调不会拦截游戏按键。键盘通过后台 Raw Input 与独立线程全局钩子监听，按系统时间戳处理重复或延迟的输入。默认透明背景，仅显示按键和条带。

**游戏请使用「窗口化」或「无边框全屏」。独占全屏可能绕过桌面合成，普通桌面悬浮窗无法保证覆盖。** 本程序不向游戏注入 DLL，不修改游戏，也不能保证对抗游戏强制置顶或特定反作弊限制。实际游戏的置顶兼容性需在你的游戏中验证。

如果以管理员身份运行的游戏收不到按键显示，可尝试将本程序也以管理员身份运行。默认普通权限即可。若快捷键被其他软件占用，设置页会提示；仍可用托盘菜单操作。

关闭或收起设置窗口只隐藏设置，悬浮窗继续运行。右下角通知区域（可能在折叠菜单内）的彩色条带图标可打开设置、切换穿透、隐藏窗口或退出。重复启动会打开已运行程序的设置。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + Alt + F8 | 打开设置 |
| Ctrl + Alt + F9 | 鼠标穿透 / 拖动模式 |
| Ctrl + Alt + F10 | 显示 / 隐藏悬浮窗 |
| Ctrl + Alt + F11 | 清零按键计数 |

计数仅保留本次运行。输入事件只在内存中用于显示，不保存逐键记录、不联网、不收集游戏数据。

## 从源码构建

在项目目录打开 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本使用 Windows 自带的 .NET Framework C# 编译器，生成 `release/KeyCascade.exe`、运行配置文件、图标与说明。分发时保留 `KeyCascade.exe.config` 和 exe 在同一目录。

开发验证：

```powershell
$testProcess = Start-Process .\release\KeyCascade.exe -ArgumentList '--self-test' -WindowStyle Hidden -PassThru -Wait
$testProcess.ExitCode
Get-Content .\release\self-test-results.txt
```

自检覆盖连发去重、双路输入去重与延迟释放、同时按键、长按/释放、漏掉释放恢复、修饰键、配置验证与原子保存、后台 Raw Input 注册、全局钩子与不拦截、窗口置顶/穿透样式和设置界面加载。全局钩子检查短暂发送并释放通常未绑定的 F24 键；请在游戏外运行自检。Raw Input 的实际硬件事件需要真实键盘验证，系统注入测试无法替代这一点。

`--render-preview <目录>` 可生成设置界面和瀑布流的离屏 PNG，用于检查布局。此预览不代表已经验证某个具体游戏的全屏置顶效果。

开发性能基准：`tools/build-benchmark.ps1` 构建独立的测试程序，报告生成在忽略的 `artifacts` 目录。测试窗口会短暂显示，不拦截按键。[性能对比与运行方法](docs/performance.md) 记录本机测试数据；提交帧率不能替代 GPU 呈现或实际游戏测试。

## GitHub 构建与下载

推送到 `main` 后，GitHub Actions 自动构建 Windows 压缩包，可在工作流的 Artifacts 中下载。推送 `v*` 标签后自动发布 GitHub Release。原生键盘监听自检需要可交互的 Windows 桌面，工作流仅编译和打包；请在本机运行上述自检命令。
